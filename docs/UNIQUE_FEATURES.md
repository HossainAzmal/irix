# ✨ Features No Other Assistant Gives You

IRIS is a **voice-first neural OS**, not a chat box. These are differentiators
that set it apart from Siri, Alexa, Google Assistant, and desktop copilots.

## 1. One control-plane for *everything*
Your **desktop**, your **phone**, and your **smart home** are driven from a
single voice/UI surface. "Dim the lights, mute my phone, and open VS Code" is
one breath — three domains, one assistant.

## 2. Phantom Control (Ghost Keyboard)
Inject keystrokes anywhere in the OS via an inline phantom input hook — dictate
straight into VS Code, terminals, or any focused field without app integrations.

## 3. ScreenPeeler (multimodal OCR)
Rubber-band select any region of the screen; IRIS runs multimodal extraction and
drops the text/code onto your clipboard — "extract code from the active window".

## 4. Cross-device notification relay
When your paired phone buzzes, IRIS **speaks the notification aloud** on your
desktop, so you never touch the phone during deep work.

## 5. Local-first, latency-obsessed
WebRTC full-duplex audio (talk while it responds), offline wake-word via Vosk,
and a disk-backed smart-home control-plane that works even when the cloud is
down.

## 6. Scene intelligence across ecosystems
Scenes match devices by **meaning** (room / kind / name), so "Movie Night" dims
*whatever* lights you own — Matter, Zigbee, or Home Assistant — in one command.

## 7. Wormhole tunneling by voice
"Expose port 3000 to the internet" spins up a public tunnel to a local dev
server — no dashboards, no config.

## 8. Deploy / macro sequences
Chain multi-step workflows ("run my deploy macro") that span shell commands,
app launches, and smart-home actions.

## 9. Vector memory of your machine
Index folders into a local semantic DB and ask "find files related to auth" —
retrieval runs on-device.

## 10. Cinematic, glassmorphic OS UI
A 3D neural core (Three.js), live telemetry HUD, and themed error HUDs — a
premium OS aesthetic instead of a chat window.
